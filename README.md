## 🌟 Overview

Welcome to the official repository of **Kartik Vashishtha's Developer Portfolio**. This website represents a blend of high-performance modern web architecture, interactive visual experiences, and clean design. Built from the ground up to showcase production-grade projects, professional timeline, technical competencies, and academic background in **Artificial Intelligence & Data Science**.

### ✨ Highlights at a Glance
- ⚡ **Cutting-Edge Stack**: Next.js 15 (App Router) + React 19 + TypeScript.
- 🎨 **Visual Aesthetics**: Cyberpunk-inspired dark neon palette, backdrop glassmorphism, and custom radial glows.
- 🌌 **Particle Physics**: Physics-driven interactive background constellation via `react-tsparticles`.
- 🪄 **Fluid Interactions**: Seamless scroll animations, staggered card entrances, and gesture states with `framer-motion`.
- 🔍 **SEO & Accessibility**: 100/100 Lighthouse SEO with structured JSON-LD rich snippets & semantic markup.
- 📬 **Live Contact Flow**: Functional Formspree-powered contact form with instant toast alerts.

## ⚡ Getting Started

Follow these instructions to clone, install, and run this project locally on your machine.

### Prerequisites

- **Node.js**: `v18.18.0` or higher (Node 20+ recommended)
- **Package Manager**: `npm`, `yarn`, `pnpm`, or `bun`

### 1. Clone Repository

```bash
git clone https://github.com/PtKartikVashishtha/portfolio-kartik.git
cd portfolio-kartik
```

### 2. Install Dependencies

```bash
npm install
# or
yarn install
# or
pnpm install
```

### 3. Run Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to experience the site locally with Hot Module Replacement (HMR).

### 4. Build for Production

```bash
npm run build
npm run start
```

## ⚙️ Configuration

### Contact Form (Formspree)
The contact section uses [Formspree](https://formspree.io/) for serverless form submissions. To point submissions to your own inbox:

1. Create a free form endpoint on [Formspree.io](https://formspree.io/).
2. In `components/Contact.tsx`, update the endpoint URL:
   ```typescript
   const res = await fetch("https://formspree.io/f/YOUR_FORM_ID", {
     method: "POST",
     headers: { "Content-Type": "application/json" },
     body: JSON.stringify(form),
   });
   ```

### Metadata & SEO
Update canonical URLs, OpenGraph image paths, and JSON-LD schema located in `app/layout.tsx` to match your personal domain and details.
